# INFERNO

A 2D cinematic platformer in the tradition of *Another World* (1991) that
adapts Dante's *Inferno* canto by canto — re-staged as a modern subway
descent. Hell is the transit system under the city; Virgil is a station
attendant; every circle is a deeper, stranger line.

## The rules in one breath

No HUD, no text, no dialogue. One camera, one art style. Death is the
teacher. Six verbs, never more, recontextualized every circle. Dante never
fights. And if a scene isn't in the poem, it isn't in the game — the modern
staging changes how it looks, never what happens.
