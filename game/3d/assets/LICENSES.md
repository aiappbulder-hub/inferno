# Third-party assets

## venice_sunset_1k.hdr
Dawn/sunset HDRI panorama used as the sky and image-based lighting.
- Source: [Poly Haven](https://polyhaven.com/a/venice_sunset) ("Venice Sunset"
  by Greg Zaal), obtained via the three.js examples repository.
- License: CC0 (public domain).

## Fox.glb
Animated low-poly fox (Survey / Walk / Run clips).
- Source: [Khronos glTF-Sample-Models](https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/Fox).
- Model: by [PixelMannen](https://opengameart.org/content/fox-and-shiba) — CC0.
- Rigging & animation: by [@tomkranis](https://sketchfab.com/tomkranis) —
  CC-BY 4.0. Attribution given here as required.

## hellhound.obj
The hound that followed Dante up from Inferno.
- Source: provided by the project owner (uploaded asset).
- Materials assigned in-code from the OBJ's usemtl groups
  (charhide / bone / claw / ember / lava).
